05 NOV 2026 · COMPUTER VISION

Separate image cleanup, text reading and rule checks

In PackSure, the OpenCV preprocessing path converts a label image to grayscale, applies a 5×5 Gaussian blur, uses adaptive thresholding, then detects contours and bounding boxes. Those regions can be passed to OCR before the extracted fields are checked against the Legal Metrology rules. One implementation detail is worth keeping clear: the current backend response after preprocessing is still simulated, so its sample OCR results should not be mistaken for live OCR output. Source code.

05 NOV 2026 · PRIVACY

Make permission choices understandable

RiMusic's project README states that the app does not collect data. It also says the audio visualizer needs microphone permission and is available only when the user enables it in Settings. The useful design lesson is simple: explain why a permission is needed and keep optional features under the user's control. Project README.
